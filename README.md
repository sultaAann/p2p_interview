# P2P_INTERVIEW

## Project Overview

**p2p_interview** is a platform that enables users to organize and conduct interviews at their convenience. Any user can act as either an interviewer, creating time slots for interviews, or an interviewee, booking available slots. The project aims to simplify the process of scheduling and coordinating interviews, offering flexibility and ease of use for all participants.

## Key Features

1. **Registration and Authentication**\
   Users can create an account by providing an email, name, and time zone to start using the platform. Authentication ensures secure access to features.

2. **Creating Interview Slots**\
   A user (as an interviewer) can create a time slot by selecting a date and time when they are available to conduct an interview. The system ensures slots do not overlap.

3. **Booking an Interview**\
   A user (as an interviewee) can browse and book available slots. The time is displayed according to the user’s time zone.

4. **Editing and Canceling Slots**\
   Interviewers can modify or cancel their slots, while interviewees can cancel their bookings. The system notifies both parties of any changes.

5. **Notifications**\
   Users receive notifications (via email, with push notifications planned for the future) about slot creation, booking, modification, or cancellation.

## Target Audience

- **Freelancers and professionals** looking to conduct or participate in interviews for knowledge sharing, hiring, or training.
- **HR specialists and recruiters** organizing interviews.
- **Any user** seeking to schedule professional or personal interviews.

## Project Value

- **Flexibility**: Users can choose their preferred time and role (interviewer or interviewee).
- **Convenience**: Time zone support and notifications streamline coordination.
- **Accessibility**: A simple and intuitive platform for all user types.

## Future Plans

- Integration with external services, such as Google Calendar, for automatic slot synchronization.
- Support for storing interview history (notes, ratings) for analysis and feedback.
- Push notifications via a mobile app.
